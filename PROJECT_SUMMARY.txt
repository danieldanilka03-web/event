1. ОБЩЕЕ ОПИСАНИЕ И АРХИТЕКТУРА СИСТЕМЫ
--------------------------------------------------------------------------------
Сервис представляет собой полнофункциональную экосистему для организации,
продажи, бронирования электронных билетов и контроля доступа на входе.
В системе реализовано 4 ключевых уровня доступа с жесткой ролевой изоляцией:
  1) Гость (неавторизованный пользователь)
  2) Участник / Зритель (Participant)
  3) Организатор мероприятий (Organizer)
  4) Администратор платформы (Admin)


2. РОЛИ И РЕАЛИЗОВАННЫЙ ФУНКЦИОНАЛ
--------------------------------------------------------------------------------

2.1. ПУБЛИЧНАЯ ЧАСТЬ И ГОСТЬ:
  - Главная витрина (Hero-секция): современный компактный баннер с быстрым
    поиском по названию/городу и моментальным фильтром по категориям
    (Конференции, Концерты, Мастер-классы, Спорт, Выставки).
  - Карточки событий: тематические яркие фотографии высокой четкости, бейджи
    статуса, шкала заполняемости мест, даты, время и место проведения.
  - Страница мероприятия: полное описание программы, информация об организаторе
    с бейджем верификации, дата, адрес и интерактивный блок схемы зала.
  - Безопасность: неавторизованные пользователи при попытке бронирования или
    доступа к защищенным панелям автоматически перенаправляются на /login
    с возвратом на исходную страницу после входа.

2.2. УЧАСТНИК (ЗРИТЕЛЬ):
  - Регистрация и вход: валидация пароля, email, защита от дубликатов, безопасная
    сессия на HttpOnly Cookie.
  - Интерактивная схема зала (SVG + Canvas):
      * Свободные места, VIP-места (с золотой короной), занятые места и места в брони.
      * Мульти-выбор: возможность выбрать до 5 мест за один заказ (ряд и номер).
      * Интерактивная плашка заказа с подсчетом количества мест и мгновенной бронью.
  - Электронный билет (QR-Pass):
      * Генерация персонального электронного билета с уникальным UUID.
      * Графический QR-код для сканирования контролером на входе.
      * 8-значный короткий номер бронирования (например, BA1F7AAC) под QR-кодом
        для быстрого ручного поиска.
      * Защищенный вид: бейдж "Действителен" / "Использован" / "Аннулирован".
      * Кнопка быстрой печати билета / сохранения в PDF.
  - Раздел «Мои билеты»:
      * Список всех активных и архивных билетов участника.
      * Переключатель связанных билетов в рамках одного мульти-заказа.
  - Личный профиль: редактирование данных (ФИО, телефон), смена пароля.

2.3. ОРГАНИЗАТОР МЕРОПРИЯТИЙ:
  - Дашборд организатора: сводные метрики продаж, количество активных событий,
    общая заполняемость залов, быстрые ссылки.
  - Управление событиями:
      * Два режима просмотра: красивые карточки событий с превью фото и шкалой
        прогресса либо компактная таблица для массового управления.
      * Создание событий: название, категория, дата/время начала и окончания,
        адрес, вместимость, описание.
      * Тематические обложки: поддержка загрузки своего URL фото либо выбор
        из готовых высококачественных пресетов по категориям.
      * Публикация, снятие с публикации, отмена и удаление событий.
  - Интерактивный список участников (/organizer/events/[id]/participants):
      * Таблица всех зарегистрированных гостей со статусами входа.
      * Быстрые фильтры: «Все», «В зале» (прошедшие контроль), «Ожидаются».
      * Живой поиск по ФИО, email, телефону или номеру места.
      * Кнопки ручной отметки входа/выхода прямо в строке таблицы.
      * Кнопка «Печать ведомости» — специальный печатный CSS-режим без лишних
        кнопок интерфейса для службы охраны/КПП.
  - Экспорт в Microsoft Excel / CSV (/api/events/[id]/export):
      * Мгновенная выгрузка всего реестра участников мероприятия.
      * Кодировка UTF-8 с BOM (\uFEFF) и разделители «;» — гарантия открытия
        в русском Excel без иероглифов и искажений.
  - Терминал контроля на входе Check-In (/organizer/events/[id]/check-in):
      * Полноценная QR-станция для контролеров на дверях.
      * Поддержка USB/Bluetooth сканеров штрих-кодов, камер и ручного ввода 8-значного кода.
      * Автофокус поля ввода для непрерывного сканирования потока людей.
      * ЗЕЛЕНЫЙ экран допуска: имя гостя, ряд, место в зале, категория билета (VIP).
      * ЗАЩИТА ОТ ДУБЛИКАТОВ (Anti-Fraud): желтое предупреждение при попытке пройти
        по уже использованному билету или скриншоту с фиксацией времени первого прохода.
      * КРАСНЫЙ экран запрета: аннулированный билет или билет от чужого события.
      * Звуковая индикация через Web Audio API (приятный перезвон при допуске,
        предупреждающий сигнал при ошибке). Возможность выключить звук тумблером.
      * Живой счетчик: «Прошло контроль: X из Y (Z%)», «Ожидается на входе».
      * Лента недавних проходов с возможностью отмены входа в 1 клик.

2.4. АДМИНИСТРАТОР ПЛАТФОРМЫ:
  - Панель аналитики (/admin): общее количество пользователей, мероприятий,
    забронированных мест и конверсия.
  - Управление пользователями (/admin/users): смена ролей (участник, организатор,
    администратор), блокировка нежелательных аккаунтов.
  - Модерация мероприятий (/admin/events): просмотр всех событий платформы,
    принудительное снятие с публикации нарушающих правила событий.


3. ТЕМАТИЧЕСКАЯ АДАПТАЦИЯ СХЕМЫ ЗАЛА
--------------------------------------------------------------------------------
Ранее схема зала всегда отображала нейтральную надпись «СЦЕНА / ЭКРАН».
Теперь схема зала динамически адаптируется под специфику каждого события:
  1) СПОРТ:
     - Фокусная зона отображает: «ПОЛЕ / АРЕНА СТАДИОНА» с изумрудной линией газона (#10B981).
     - Заголовок секции: «Выбор места на трибуне».
  2) КОНЦЕРТЫ:
     - Фокусная зона: «ГЛАВНАЯ СЦЕНА / МУЗЫКАНТЫ» с фиолетовым сценическим подиумом.
     - Заголовок секции: «Выбор места в концертном зале».
  3) КОНФЕРЕНЦИИ:
     - Фокусная зона: «ПРЕЗИДИУМ / ЭКРАН ДОКЛАДЧИКА» с индиго-подсветкой.
     - Заголовок: «Выбор места в конференц-зале».
  4) МАСТЕР-КЛАССЫ:
     - Фокусная зона: «ЗОНА ВЕДУЩЕГО / ДЕМОНСТРАЦИОННЫЙ СТОЛ».
  5) ВЫСТАВКИ:
     - Фокусная зона: «ЭКСПОЗИЦИЯ / ЦЕНТРАЛЬНЫЙ ПАВИЛЬОН».


4. СХЕМА БАЗЫ ДАННЫХ И МИГРАЦИИ
--------------------------------------------------------------------------------
База данных работает на PostgreSQL (Neon).
Применены 6 миграций схемы:
  - 0000_init: таблицы users, events, waitlist.
  - 0001_seats: таблица seats (ряды, номера, категории VIP/стандарт, привязка к залу).
  - 0002_multi_seat: поддержка связывания нескольких регистраций в один заказ.
  - 0003_event_images: поле image_url в таблице events для обложек событий.
  - 0004_fix_empty_desc: миграция очистки тестовых описаний событий.
  - 0005_check_in: добавление колонки checked_in_at (timestamp with time zone)
    в таблицу registrations для фиксации времени прохода через турникет/КПП.
